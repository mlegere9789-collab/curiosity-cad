# Archived: from-scratch AutoCAD-parity CAD program

This folder holds the original project concept: an independent, free, cross-platform CAD application built from scratch to reach full feature parity with AutoCAD 2026.

That concept was superseded on 2026-09-16 in favor of a far more achievable project: a natural-language plugin for real AutoCAD (Windows), since the actual audience (the project owner + classmates) already has genuine AutoCAD licenses through school. See the repo root `README.md` and `STATUS.md` for the current, active plan.

These files are kept for reference only — the pain-point research and requirements catalog in them (`PAIN_POINTS_AND_REQUIREMENTS.md`, `FEATURE_CATALOG.md`) are still useful source material for prioritizing what the plugin should fix first.
